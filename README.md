# Shablam queen photos

Static image host for the queen portraits shown in [Shablam](https://github.com/saarhaber/Shablam).

Served over GitHub Pages:

```
https://saarhaber.github.io/shablam-queen-photos/queens/<slug>_512.webp
https://saarhaber.github.io/shablam-queen-photos/queens/<slug>_128.webp
```

`<slug>` is the queen's name lowercased, accents folded, punctuation to hyphens —
`Monét X Change` is `monet-x-change`. The slug rule lives in `QueenKey.kt` and
`queen_photos/slug.py` in the app repo.

The images are official cast mugs from the [RuPaul's Drag Race
wiki](https://rupaulsdragrace.fandom.com), resized to 512px and 128px. They are
promotional stills owned by the productions, not freely-licensed work; each row in
the app's database credits the wiki as the source.

Regenerated by `tools/queen-photos` in the app repo. Nothing here is edited by hand.
